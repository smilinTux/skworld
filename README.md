# SKWorld

SKWorld is part of the software lifecycle shared by SKCapstone, SKDashboard,
and SKWorld.

## Recursive SELF Improvement

[SK Recursive SELF Improvement](https://github.com/smilinTux/skrsi) provides
the reusable architecture for improving this lifecycle. SELF means
**Systematic Evaluation, Learning, and Feedback**.

This lifecycle scope does not define or include an SKLegal lifecycle role.
